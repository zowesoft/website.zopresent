# Your first service

The studio is built around one loop: **fill the preview, send it live**.
Nothing reaches the audience display without a deliberate keystroke, so a
mis-click can never project the wrong slide mid-service.

## The two windows

- **Studio window** — the operator's view: service order, preview, live
  output, search, and the detection queue.
- **Audience display** — a separate window that mirrors the live output and
  nothing else. Drag it onto the projector and make it full screen.

If no second display is connected, the media editor doubles as the player so
you can still rehearse on one screen.

## More than one service

The **home page** lists your saved services — the active one first — and
**New service** (or `Ctrl+N`, or File → New Service) starts another one.
Each service keeps its own running order and its own decision history, so
last Sunday's projections never blur into this Sunday's. Pick a service to
continue it.

## Building the order

Add items to the service order from the toolbar:

1. **Scripture** — type a reference like `Jn 3:16` or a range like
   `John 3:16-18` and press Enter. Word, phrase and prefix search also work —
   see the [Bible library](/docs/bible-translations).
2. **Songs** — add a whole arrangement or a single section from the song
   library.
3. **Media** — images, audio and video from the media library.
4. **Custom items** — announcements, titles, anything else.

Select an item to load it into the preview, where you can check it before
anyone sees it.

## Sending it live

Press **Ctrl+L** (or click **Send live**) to put the previewed item on the
audience display. Step through the order with **←** / **→**.

## When something goes wrong

Every send is recorded in the **decision history**. If the wrong item went
live, restore the previous one from history — the screen never has to sit
blank while you hunt for what was up a minute ago.

## How a long passage becomes slides

Under **Settings → Slides**, choose how a multi-verse passage splits:

- **One verse per slide** — fills the wall with the verse being read and puts
  every verse in its own row on the order. Good for following a preacher who
  reads verse by verse.
- **Whole passage** — keeps the passage together on one slide.

Themes control how each of these looks — see [themes](/docs/themes).

## Rehearse detection before the service

If you plan to use [scripture detection](/docs/detection) during the service,
turn it on during a rehearsal or sound check first — the
[audio input](/docs/audio-input) guide covers the setup that makes it work.
